## Crates

<CardGrid>
	<Card title="vyasa-patha" icon="random">
		Vedic & Classical Sanskrit recitation generator (Pada-pāṭha, Krama-pāṭha, Vikṛti pāṭhas) with Pragṛhya detection, Parigraha formatting, and multi-script output. See the <a href="reference/vyasa-patha/">CLI & API reference</a> and <a href="explanation/recitation-modes/">recitation modes explanation</a>.
	</Card>
	<Card title="vyasa-lipi" icon="pencil">
		Universal, lossless multi-script Sanskrit transliteration engine supporting 11 Indic, Roman, and ASCII formats with Vedic pitch accent preservation. See the <a href="reference/vyasa-lipi/">CLI reference</a> and <a href="guides/transliterate-sanskrit/">user guide</a>.
	</Card>
	<Card title="vyasa-phonetics" icon="open-book">
		Pre-Pāṇinian (Ṛgveda-Prātiśākhya), Pāṇinian (Śiva Sūtras), and Śikṣā articulatory phonetic models in zero-dependency Rust. See the <a href="reference/vyasa-phonetics/">crate reference</a> and <a href="explanation/sanskrit-phonetics/">phonetics explanation</a>.
	</Card>
	<Card title="mpt" icon="document">
		Multi-part-text format — parse, validate, and manipulate plain-text records with multiple sections. See the <a href="reference/mpt/">CLI reference</a>.
	</Card>
	<Card title="walk" icon="open-book">
		Folder hierarchy traversal with config inheritance, ignore rules, and path metadata inference.
	</Card>
	<Card title="pack" icon="setting">
		Compile `.mpt` records and schemas into an immutable SQLite package for static delivery.
	</Card>
	<Card title="render" icon="puzzle">
		Narrative documents (Word, Google Docs, Markdown) from structured data — planned.
	</Card>
