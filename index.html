Crates

Section titled “Crates”

vyasa-patha

Vedic & Classical Sanskrit recitation generator (Pada-pāṭha, Krama-pāṭha, Vikṛti pāṭhas) with Pragṛhya detection, Parigraha formatting, and multi-script output. See the CLI & API reference and recitation modes explanation.

vyasa-lipi

Universal, lossless multi-script Sanskrit transliteration engine supporting 11 Indic, Roman, and ASCII formats with Vedic pitch accent preservation. See the CLI reference and user guide.

vyasa-phonetics

Pre-Pāṇinian (Ṛgveda-Prātiśākhya), Pāṇinian (Śiva Sūtras), and Śikṣā articulatory phonetic models in zero-dependency Rust. See the crate reference and phonetics explanation.

mpt

Multi-part-text format — parse, validate, and manipulate plain-text records with multiple sections. See the CLI reference.

walk

Folder hierarchy traversal with config inheritance, ignore rules, and path metadata inference.

pack

Compile .mpt records and schemas into an immutable SQLite package for static delivery.

render

Narrative documents (Word, Google Docs, Markdown) from structured data — planned.
